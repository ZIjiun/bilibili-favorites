# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack
Existing: one self-contained HTML file (no build step, no external libraries, system fonts only), generated by a script from the user's Bilibili favorites data, then encrypted (WebCrypto PBKDF2 + AES-GCM password gate) and published to GitHub Pages.

## Users
One person (the owner), on desktop and phone about equally, searching and browsing ~635 saved Bilibili videos spread over 28 folders. Job: find a specific video fast (by remembered keyword, creator or topic) or browse a topic area.

## Product Purpose
A personal searchable catalog of Bilibili favorites, so videos saved over years can be found again. Success: the owner finds the video in seconds without opening Bilibili's folder UI.

## Positioning
A catalog built on the owner's own folder taxonomy (13 groups, 28 folders), searching all folders at once, with thumbnails, in Traditional Chinese (Taiwan usage; creator names left as-is).

## Operating Context
Opened from a browser, often after a nightly automatic refresh. Search runs across title, creator, intro and folder name. Data is a snapshot regenerated daily. Videos open in Bilibili in a new tab.

## Capabilities and Constraints
- Single HTML file, works offline except cover images (Bilibili CDN, no referrer).
- Light, beige and dark themes, plus auto, user-selectable.
- Password-gated; the page is public on GitHub Pages, so the gate must not break.
- Folder count and names change over time; layout must tolerate new groups/folders.
- Chinese text only (Traditional); keyboard "/" focuses search.

## Brand Commitments
Pinned by the owner: a game stage-select world map. One continuous island on the sea; each top-level group is a region with its own ground material and one big landmark on a pedestal, an icon-plus-name badge and a count bar. Folders stay off the map and appear as chips after a region is picked. Landmarks are drawn in SVG code in a clean outlined game-illustration style (no copying of the reference game). Themes: light, beige, dark, auto. Rejected looks: nautical sea chart, isometric tile board.

## Evidence on Hand
Real data: 635 videos with titles, creators, durations, dates, intros and cover paths (embedded in the page). No testimonials or external claims.

## Product Principles
1. Finding beats looking: search and filter are never more than one action away.
2. The map is navigation, not decoration: every island is a working control that shows true counts.
3. Thumbnails are the content; the chrome stays out of their way.
4. Readable at a glance on a phone, comfortable on a wide monitor.
5. Survive change: new folders and groups appear without hand-placing them.

## Accessibility & Inclusion
Contrast at least 4.5:1 for text, visible focus, controls reachable by keyboard, no information carried by color alone.
